# STRANGERTHINGS

A 2D supernatural adventure platformer inspired by the world of **Stranger Things**.

## 🎮 Game

Explore a mysterious 1980s-inspired world, overcome obstacles, solve puzzles, fight supernatural enemies, and survive the transition between two dimensions.

### Core Features

* 2D platforming
* Multiple levels
* Dimension switching
* Enemy encounters
* Collectibles
* Puzzles
* Atmospheric effects
* Sound system
* Collision and level management
* Browser-based gameplay

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Canvas
* Git & GitHub

## 🚀 Running the Game

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/STRANGERTHINGS.git
```

Open the project folder and run it using a local server.

For example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
